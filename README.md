# Reality Fracture Prerelease Field Guide

A compact, offline-friendly Magic: The Gathering Reality Fracture sealed guide for the September 25, 2026 prerelease.

Open `index.html` in any browser, or visit the [published guide](https://kurtzgpt.github.io/reality-fracture-prerelease-guide/). The page includes sealed deck-building advice, all ten color-pair plans, all 38 main-set common and uncommon instants and flash cards, and tap-to-enlarge photos of all 71 distinct cards named in the guide. The images live in `images/`, so a saved copy works offline. `cards.json` records each image's Scryfall source and set printing.

Card and rules details were checked against Wizards of the Coast's prerelease guide, release notes, and mechanics article on September 24, 2026. Card images are provided by Scryfall; Magic: The Gathering card art and text are © Wizards of the Coast. This is an independent fan quick reference.
