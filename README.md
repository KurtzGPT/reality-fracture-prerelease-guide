# Reality Fracture Prerelease Field Guide

A compact, offline-friendly Magic: The Gathering Reality Fracture sealed guide for the September 25, 2026 prerelease.

Open `index.html` in any browser. No build step, account, or network connection is required after the file is saved. The page includes deck-building numbers, all ten color-pair plans, interaction by open mana, and rules reminders. Source links are included at the bottom of the page.

Card and rules details were checked against Wizards of the Coast's prerelease guide, release notes, and mechanics article on September 24, 2026. This is an independent fan quick reference.
